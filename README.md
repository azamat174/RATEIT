# 🎵 RATEIT - Social Rating Platform\n\n> Rate user-generated content from 1 to 100. Comment, reply, and react in real-time.\n\n## ✨ What is RATEIT?\n\nRATEIT is a modern social platform where users upload content across 6 categories and the community rates it from 1-100. Users can comment, reply, react with emojis, and get real-time notifications.\n\n## 🚀 Features\n\n✅ **User Authentication** - Secure sign up & login  \n✅ **6 Content Categories** - Tracks, Works, Outfits, Appearance, Photos, Ideas  \n✅ **Rating System** - Rate 1-100 with auto emoji indicators  \n✅ **Comments & Replies** - Nested discussions (2 levels)  \n✅ **Reactions** - ❤️ 🔥 😂 👍 👎 on comments  \n✅ **Real-time Notifications** - Get notified of interactions  \n✅ **User Profiles** - Bio, stats, and post history  \n✅ **Search & Discovery** - Find posts and users  \n✅ **Top Posts** - Trending by time period and category  \n✅ **Mobile Optimized** - Fully responsive  \n✅ **Security** - Row Level Security on all data  \n✅ **File Storage** - Images and audio uploads  \n\n## ⚡ Quick Start\n\n### Prerequisites\n- Node.js 18+\n- Supabase account (free)\n\n### Setup (5 minutes)\n\n```bash\n# 1. Clone\ngit clone https://github.com/azamat174/RATEIT.git\ncd RATEIT\n\n# 2. Install\nnpm install\n\n# 3. Setup environment\ncp .env.local.example .env.local\n\n# Add Supabase credentials to .env.local\n# NEXT_PUBLIC_SUPABASE_URL=...\n# NEXT_PUBLIC_SUPABASE_ANON_KEY=...\n# SUPABASE_SERVICE_ROLE_KEY=...\n\n# 4. Setup database (run migrations in Supabase SQL Editor)\n# supabase/migrations/001_init.sql\n# supabase/migrations/002_functions_triggers.sql\n\n# 5. Create 'posts' storage bucket in Supabase (make public)\n\n# 6. Run\nnpm run dev\n```\n\nOpen http://localhost:3000\n\n## 📋 Testing Checklist\n\n- [ ] Register & Login\n- [ ] Create post in each category\n- [ ] Rate post (1-100)\n- [ ] Comment & reply\n- [ ] Add reactions\n- [ ] Get notifications\n- [ ] Edit & delete own post\n- [ ] Search users/posts\n- [ ] View top posts\n- [ ] Mobile responsive\n\n## 🏗️ Tech Stack\n\n**Frontend**\n- Next.js 14 (App Router)\n- React 18 + TypeScript\n- Tailwind CSS + Shadcn/ui\n- Framer Motion (animations)\n\n**Backend**\n- Supabase (PostgreSQL)\n- Supabase Auth\n- Supabase Storage\n- Supabase Realtime\n\n**Tools**\n- React Hook Form + Zod\n- Zustand (state)\n\n## 📁 Project Structure\n\n```\nsrc/\n├── app/                    # Pages\n│   ├── page.tsx           # Home\n│   ├── feed/              # Feed\n│   ├── posts/[id]/        # Post detail\n│   ├── upload/            # Upload form\n│   ├── profile/           # User profile\n│   ├── notifications/     # Notifications\n│   ├── search/            # Search results\n│   ├── top/               # Top posts\n│   └── auth/              # Login/signup\n├── components/\n│   ├── auth/              # Auth components\n│   ├── layout/            # Header/footer\n│   ├── posts/             # Post components\n│   ├── upload/            # Upload form\n│   └── ui/                # Basic UI\n└── lib/\n    ├── auth/              # Auth context\n    ├── supabase/          # Supabase config\n    └── utils.ts           # Helpers\n```\n\n## 💾 Database\n\n- **users** -
